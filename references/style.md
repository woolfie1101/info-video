# 화면 스타일

깔끔한 한국 지식 설명 유튜브 형식을 분석해 정리한 것. 특정 채널의 로고·이름은 쓰지 않고, 채널명은 config에서 정한다.

## 고정 화면 틀
- 왼쪽 위: 채널명(흰 굵은 글씨 + 검은 테두리) + 소주제 이름표(어두운 바, 왼쪽 노란 선)
- 아래 가운데 자막: 반투명 검정 둥근 바, 흰 굵은 고딕, 왼쪽 세로선(기본 버건디). 한 번에 한 구절
- 쇼츠형: 검은 바탕, 위 2줄 제목(흰색 + 노랑 강조), 가운데 정사각 영상, 영상 안 하단에 흰 글씨 + 검은 외곽선 자막, 맨 아래 회색 계정명

## 그래픽 스타일
- 막대그래프: 구겨진 흰 종이 질감 배경 + 남색 막대, 말풍선형 수치 태그, 강조 막대는 빨강. 제목 가운데, 출처 오른쪽 아래
- 아이콘 카드: 굵은 검정 테두리의 평면 벡터 아이콘 + 흰 카드, 번호 동그라미(노랑)
- 인용 카드: 검정 배경 + 방사형 빛줄기, 명조체 흰 글씨, 핵심어만 노랑
- 숫자 비교: 두 카드, 파랑(이전)과 빨강(이후), 숫자가 0부터 올라감

## 모션 (프레임 단위 분석 결과)
- 막대: 제목·축 먼저, 막대가 아래에서 빠르게 자람(약 0.5초), 수치 태그는 아래→위로 닦이듯 등장. 내레이션 박자에 맞춰 막대별로
- 인용: 글자가 한 자씩 타자 치듯, 배경 빛줄기는 천천히 회전
- 카드: 하나씩 튀어나옴(살짝 커졌다 돌아오는 오버슛)
- 실사: 약간 어둡게 + 가장자리 비네팅. 화면 전체 줌(켄번스)은 쓰지 않음
- 편집: 3~8초마다 화면 전환, 문장 사이 쉼 거의 없이 빠른 진행
